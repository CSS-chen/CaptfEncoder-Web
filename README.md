# CaptfEncoder Web

A browser version of [CaptfEncoder](https://github.com/guyoung/CaptfEncoder), built as a static SPA and deployable to Vercel. Every calculation runs locally in the browser — there is no backend, database, or server-side function.

[中文文档](README-zh.md)

- **72 tools**: encoders, classical ciphers, cryptography, public-key crypto, special encodings and file/image utilities
- **Online tools removed**: whois / IP ASN / IP info / IP Whois / Factordb (they require a server-side proxy and cannot run as a static site)
- **Python dependencies removed**: Gronsfeld cipher and hash identification were ported to JavaScript
- **Vue 2.7 + Vuetify 2.7 + webpack 5**

## Requirements

- Node.js >= 18 (20 / 22 recommended)
- npm 9+

## Development

```bash
npm install
npm run dev
```

Open <http://localhost:8080>.

`npm run dev` regenerates the extension manifest (`scripts/gen-manifest.js`) and starts webpack-dev-server with hot reload.

## Build

```bash
npm run build     # outputs to dist/
npm run preview   # serve dist/ locally
```

## Deploy to Vercel

Import the repository into Vercel and keep the settings from `vercel.json`:

- Framework Preset: **Other**
- Build Command: `npm run build`
- Output Directory: `dist`

The router uses hash mode (`/#/extensions/...`), so no SPA rewrite is required.

## Testing

The project includes a Puppeteer smoke test that exercises representative algorithms, file uploads, QR codes, GIF extraction, EXIF parsing, and renders all 72 extension pages.

```bash
npm run build
npm run preview        # http://localhost:3000

# in another terminal
BASE_URL=http://localhost:3000/ npm run smoke
```

PowerShell:

```powershell
$env:BASE_URL="http://localhost:3000/"; npm run smoke
```

The test uses the locally installed Chrome. Set `CHROME_PATH` if Chrome is installed elsewhere.

## Project structure

```
extensions/              # extension views + controllers (reused from upstream)
extensions-disabled/     # online tools removed from the web build
config/                  # languages, themes, catalog
src/                     # Vue application shell
  extensions-registry.js # browser registry replacing Electron IPC
  generated/             # manifest generated by npm run gen
  plugins/commands.js    # file / download / clipboard Web APIs
scripts/
  gen-manifest.js        # scans extensions/ at build time
  smoke-test.js          # Puppeteer smoke test
webpack.config.js
vercel.json
```

## Notes

Implementation details (Electron-to-Web mapping, Node dependency replacements) are documented in [docs/IMPLEMENTATION.md](docs/IMPLEMENTATION.md).

- All tools run client-side. Uploaded files never leave the browser.
- Extensions are bundled at build time; runtime hot-plugging is not supported.
- Vue 2 / Vuetify 2 are end-of-life. This choice maximizes reuse of the upstream view components.
- Hash identification uses the `name_that_hash` rule table vendored in the upstream project.
- Very large file hashing is limited by browser memory.
